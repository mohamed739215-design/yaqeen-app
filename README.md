# يقين - نظام الحضور المحلي

تطبيق تسجيل حضور الطلاب يعمل **100% بدون إنترنت** مع تخزين محلي بالكامل (IndexedDB).

## المميزات

- ✅ مسح QR Code لتسجيل الحضور (كاميرا الموبايل)
- ✅ تسجيل يدوي للحضور
- ✅ إدارة قائمة الطلاب (إضافة / تعديل / حذف)
- ✅ توليد كارت QR لكل طالب
- ✅ سجل حضور اليوم مع إحصائيات
- ✅ سجل تاريخي
- ✅ تصدير البيانات (JSON / CSV)
- ✅ استيراد بيانات من نسخة احتياطية
- ✅ حماية برمز PIN
- ✅ يعمل كتطبيق مثبت (PWA) على أندرويد و iOS
- ✅ واجهة عربية RTL بالكامل
- ✅ تصميم مشابه لتطبيق Student Track

## طريقة التشغيل

### الطريقة الأسهل (موصى بها):
1. انسخ مجلد `yaqeen` إلى هاتفك أو الكمبيوتر.
2. افتح ملف `index.html` في متصفح Chrome أو Edge.
3. أو ارفع المجلد على أي استضافة ثابتة (مثل GitHub Pages أو Netlify).

### للتثبيت كتطبيق على الأندرويد:
1. افتح التطبيق في Chrome.
2. من قائمة المتصفح اختر **"إضافة إلى الشاشة الرئيسية"** أو **"تثبيت التطبيق"**.
3. سيظهر أيقونة "يقين" كتطبيق عادي.

### للتجربة محلياً مع سيرفر:
```bash
cd yaqeen
python3 -m http.server 8080
```
ثم افتح: http://localhost:8080

## الرمز الافتراضي
عند أول تشغيل يكون الرمز: **1234**  
يمكنك تغييره من القائمة الجانبية.

## التخزين
جميع البيانات محفوظة محلياً في متصفح الجهاز باستخدام **IndexedDB**.  
لا يتم إرسال أي بيانات إلى أي خادم خارجي.
